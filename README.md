# Проект: виджет банковских операций клиента

## Цель проекта
В рамках обучения языку программирования Python, разработать виджет банковских операций клиента.

## Добавлены функции

-- **filter_by_currency()** -  Фильтрует банковские операции по валюте
    принимает на вход список словерей банковских операций и параметр фильтрации
    возвращает итерируемый объект
    
-- **transaction_descriptions()** - Возвращает описание транзакций по очереди принимает список словарей с транзакциями
    возвращает итерируемый объект

-- **card_number_generator()** - генератор, который выдает номера банковских карт в формате XXXX XXXX XXXX XXX, где X — цифра номера карты принимает на вход стартовое и конечное значение
возвращает номер банковской карты от 0000 0000 0000 0001 до 9999 9999 9999 9999

-- **read_csv_transactions()** - позволяет читать данные из csv файла, на выходе передает список

-- **read_excel_transactions()** - позволяет читать данные из xlsx файла, на выходе передает список
Функции могут быть использованы для предобработки данных перед выводом пользователю или дальнейшего анализа.
